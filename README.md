## 🎯 Project Overview

The objective of this project is to explore a used cars dataset, understand its features, identify missing values, check duplicate records, detect potential outliers, and visualize patterns in the data.

## 🛠️ Tools & Technologies

- 🐍 Python
- 🐼 Pandas
- 📊 Matplotlib
- 🎨 Seaborn
- ☁️ Google Colab

## 🔍 Work Completed

- 📋 Explored the dataset using `head()`, `info()`, and `describe()`
- 🔎 Analyzed missing values and their percentages
- 🔁 Checked for duplicate records
- 📈 Performed univariate analysis
- 🔗 Performed bivariate analysis
- 📦 Visualized potential outliers using boxplots
- 🧮 Practiced outlier detection using the IQR method
